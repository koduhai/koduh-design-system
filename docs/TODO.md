## Near-term (gaps & polish)

### Component / API gaps

- [ ] **`DataTable` virtualization + row expansion** (follow-up to #37) — #37
      shipped fixed-height windowing that coexists with sort/filter/selection/
      sticky-header/resize, but it falls back to pagination when `renderExpanded`
      is set (variable-height detail rows break fixed-height windowing). A
      measure-based windowing pass would let the two combine.
- [x] **Public `Form` reset / `setValues` ergonomics** (#92) — `reset()` /
      `reset(values)` and `setValue` were already correct; added a bulk
      `setValues(patch)` for the "load server values" case and documented the three
      in `MIGRATION.md`, with tests. On `main`.

### Cross-browser / platform polish

- [x] **Firefox / Safari overlay placement** (#40) — the JS positioning fallback is
      now exercised on WebKit + Firefox in CI (`e2e/interactions.spec.ts`) and
      passes; the fallback is confirmed correct, not just assumed.
- [x] **`prefers-reduced-motion` audit** (#93) — audited the whole library: the
      global `reset.css` rule (zeroes CSS transition/animation durations) plus
      per-component guards already covered everything; added the missing `Stepper`
      label-transition guard and a `CountUp` snap-without-animating test (the one
      JS-driven motion). On `main`.
- [ ] **SSR theme-flash snippet** — consider shipping a tiny `<KoduhThemeScript />`
      server component for Next.js App Router users.

### Accessibility

- [x] **Live-region announcer primitive** (#40) — `<LiveRegion>` + `useAnnouncer()`
      shipped; Carousel/TagInput migrated, Combobox announces result counts.
      (CommandPalette/DataTable can adopt `useAnnouncer()` incrementally.)
- [x] **Backfill a11y coverage docs** (#94) — `ACCESSIBILITY.md`'s per-component
      table extended 12 → all 81 components; the automated-coverage note now points
      at the `e2e/components.spec.ts` axe matrix (the real enforcement). On `main`.
- [x] **`Tree` `aria-multiselectable`** (#91) — Tree is single-select (`selectedId`),
      so it now declares `aria-multiselectable="false"` explicitly, with tests. On
      `main`.
